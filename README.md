# BioCraft

Site for the BioCraft Fall 2026 Bioethics course — Next.js App Router, TypeScript, plain CSS.

## Develop

```bash
npm install
npm run dev
```

## Structure

- `app/` — routes: `/` (home), `/curriculum`, `/about`
- `content/` — curriculum and team data
- `components/` — `Nav`, `Footer`
- `CONTENT-TODO.md` — placeholder content that needs real copy before launch

## Design reference

`gemini-code-1784817804614.html` is the certificate generator this site's visual system (tokens,
type, red/blue accents) was lifted from. It is not part of the site — kept for reference only.
